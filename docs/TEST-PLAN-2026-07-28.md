# Test plan — 28 July 2026

Everything below is **live on prod**. It is ordered by **risk**, not by the order it was built:
the further down you get, the less it matters if you run out of time.

I could only verify that code is present and that prod is healthy. **Nothing here has been seen

## 1. HIGH RISK — never executed once, anywhere

These change how files reach storage. If one is broken, a sponsor or speaker cannot deliver
their material at all.

### 1.1 Direct-to-storage uploads (§494)
The file now goes **browser → SharePoint directly**, never through the hub. Test each surface:

| Where | File to use | Expect |
|---|---|---|
| Company Details → **collateral** | any PDF | progress %, page reloads, file listed |
| Company Details → **SoMe logo** | PNG | as above, appears as `SoMeBrandingLogo_<you>_v1.png` |
| Company Details → **print logo** | EPS/AI/PDF | `PrintLogo_…_v1` |
| Company Details → **Zoho logo** | PNG | `ZohoLogo_…_v1` |
| Company Details → **exhibitor wall** | large PDF (**try >100 MB**) | the real prize — this is capped at 1 GB |
| Speaker → **upload deck** | PPTX | version increments, the deadline task flips to Done |

**What "good" looks like:** a progress percentage that climbs, then the page reloads with the file
listed. **What tells you it fell back:** a red message ending *"Press the upload button again to
retry using the standard upload."* — that is the fallback working as designed, not a crash, but
please tell me, because it means the direct path failed.

**Also check the version numbers keep counting** (`_v1`, `_v2`) if you upload twice. Both routes
must produce the same names.

### 1.2 Speaker photo upload (§469)
This was **broken until tonight** — the destination folder was never configured. Get Started →
*Your speaking session* → add a speaker photo.
**Expect:** it saves. **The old symptom was:** *"Photo uploads aren't available right now."*

### 1.3 Contact add / remove (§482b)
Company Details → contacts → add a contact, then remove one.
**Expect:** the save returns **immediately** (the sync now runs behind), and within a few seconds
the *Linked Event Coordinators* list on Sponsor Tasks reflects it.
**Tell me if:** the save feels slow — it shouldn't any more.
